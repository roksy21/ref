🚨Смотри чтобы запустить бота вым нужно заменить свои данные в файле config.py🚨

🚨для запуска🚨
pip install бот.py 

🚨нужно загрузить библиотеки🚨
pip install aiogram==2.13 telethon requests

фото меняй на какое хочешь главно название должно быть одинаковое 

также после заменны данных добавляешь бота в канал и даешь админу, для извлечение названия и ссылки 

если зделать ссылку платную то для работы бота нужно будет заплатить за вход в канал 

📢Напоминаю что частое использивание одного акк для сноса может прывлечь внимание тг поддержки и его могут удалить📢
